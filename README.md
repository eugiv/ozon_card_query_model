# Модель «фраза подходит карточке»

Офлайн-модель отделяет фразы, по которым у карточки был заказ, от фраз,
которые карточку показывали и заказа не было.

Ответ берётся из следующих недель. Частота, конверсия и заказы прошлого
окна в ответ не входят. Место в выдаче в модель не входит.

## Как запустить

Учётные данные читаются из `.env` репозитория `clickhouse_dbt`
(`DBT_CLICKHOUSE_*`). Файл с паролем сюда не копируется.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python src/train.py
```

Журнал экспериментов — локальный MLflow на SQLite. Файл `mlflow.db`
создаётся командой обучения на этой машине и в git не входит.
Облачный аккаунт не используем: в журнал попадают тексты запросов.
Сводка последнего прогона — `reports/metrics.json`.

Карточки с менее чем тремя парами с заказом в обучение не входят.
Для них решение описано в `src/sparse_rules.py`.
